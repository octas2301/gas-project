## 1. 目的

`00_設定マスタ` の A=`FBA手数料` が **2023/4 体系**（例: 標準2a=40cm/434円）のままのため、料金シミュレーター（缶飯→**415円・標準2b**）と乖離している。  
**Amazon 公式の現行配送代行手数料（1,000円超）** に D（金額）・F（条件）・行構成を合わせる。

## 2. 出典（正）

| 項目 | 内容 |
|------|------|
| 公式 | [Amazon出品サービスの料金（JP）](https://sell.amazon.co.jp/pricing?mons_sel_locale=ja_JP) 「FBA配送代行手数料」 |
| 突合 | 料金シミュレーター ASIN `B084RJSH7W` → 出荷費用 **415円**（標準2b相当） |
| 適用 | **価格が1,000円を超える商品**の行を D 列の正とする |
| 備考 | 1,000円以下は別レート。本更新の D 列には載せない |

## 3. 変更（実施）

| 対象 | 内容 |
|------|------|
| `00_設定マスタ` | A=`FBA手数料` のみ。行20〜40に現行表。販売手数料は行41以降へ**自動シフト**（内容未改変） |
| 手順スクリプト | `tools/c1_hpc_packaged/update_fba_fee_table_00.py` |
| コード.js | **変更なし** |

### 追加のやり方（実施済み）

**FBAブロック末尾（販売手数料の直前）に行を挿入**してから A/B/D/F のみ更新。  
他カテゴリ（販売手数料等）のセル値は書き換えない。コードは A列キー読取のため行番号ずれの影響は原則なし。
