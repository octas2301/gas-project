## 1分凡例

| 見える色 | 意味 | 人がやること |
|----------|------|----------------|
| **水色の行** | 親SKU行 | 行の塊の起点として見る |
| **薄い赤（親の一部セル）** | 親・赤白チェック（親だけ必確認） | レ点・入力を確認。青字レ点が読める色 |
| **黄セル** | 人が入力・選択・見て修正する場所 | 必要なら直す。**色はそのままでよい** |
| **緑セル** | 上流確定をプログラムが転記 | 通常は触らなくてよい |
| **ピンクセル** | プログラムが後から上書きした | 前と違うか確認 |
| **灰** | 式／転記／触らない | 触らない |
| **白** | 未使用／親のみ（子は空） | 子では触らない想定 |
| **オレンジ** | ソフト警告（**必要になったら追加**） | 余裕があれば見る |
| **濃赤＋白字** | エラー（利益不足等） | **必ず確認** |

子行に薄いピンクの「地色」は **公式ではない**。条件付き書式は **触らない**。

## 黄について（よくある誤解）

- N列ASIN自動・競合ASIN空のみ・自社品番の黄も、**「人が見て直す場所」**という意味で同じ黄  
- **確認したあと黄を消す必要はない**  
- 列全体が最初から黄色い欄＝人が入れる欄の印（消さない）

---

## 親行

- 行の地は水色  
- 区分・サイズ自己発/FBA・バリエーション系など指定列だけ薄い赤（赤白チェック）  
- エラー時のみ濃赤＋白字（赤白チェックとは別）
