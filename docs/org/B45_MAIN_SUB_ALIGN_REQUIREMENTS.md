2. **合格一片を採用** → セット01に**コピーで残す**。02〜は外形差分のみ（材質・色・縁は継承）。  
3. **セット全枚を機械言語化**（形状／縁／色透過／表面／厚み硬さ／**部位暗色の有無**）。`piece_set_lang.json` に保存。  
4. **人間修正**は「画像だけ」禁止。**必ず言語化も直す**（`--note` を該当片の文へ反映）。  
5. **場面（案G）**  
   - 小皿: IDENTITY先頭（配置）＋セット。量は**適量**（疎らカタログも過剰山盛りも禁止）。顧客目的文を入れる。  
   - 料理（卵かけ等）: セット複数片・実寸・湿りなじみ。1本の長大帯禁止。各片は写真＋**その片の言語化**が正。  
6. **既知の弱点（料理・盛り）**: 全面再生成は個品が別物になりやすい。  
7. **不合格（2026-11-06 人間判定）**: **後乗せ合成（切り抜き貼付・stamp／nudge）は不合格**。白ハロー・一体感欠如のため本線候補にしない。仮想 `_tmp_food_piece_ba_stamp_virt.py` は記録用のみ。  

**レビューの見方**: 段階を跨いで一片を作り直すと、人間の修正指示がぶれる。合格片は引き継ぎ、差分と文だけ直す。  
**残課題**: 後乗せなしで、一片セットの見た目を場面に残す生成手段。合成に戻さない。  
**仮想試行（2026-11-06）**: `_tmp_food_piece_gen_lock_virt.py` … G2＝一片添付先頭＋描き直し禁止＋全片言語化／G3＝空下地→生成で載せる（画素貼付ではない）。人間検収待ち。

### 7.16 サブのミックス（単品の生成は残す）

単品のサブ生成は、この節では変えない。セット構成1が空の親は単品のまま。空でない親だけ、次を足す。商品名の「・」では分けない。紐づく単品が1種類しか取れない親は、単品に戻す。構成の数は、空でない構成の数。上限は5。

文。言う内容は、揃っている種類の数で分ける。長い左右の特徴の説明と、個品の見本片は、テーマで分ける。素材の1枚だけ、左右に特徴を書き、見本片を出す。シズル、味、セット内容は、見本片を主役にして名前と内容量だけ書く。食べ方、アレンジ、日常は、見本片を置かず料理の上だけに両方を載せる。アレンジは候補の料理を最大3つ、ほかの料理は1つ。それ以外のテーマは、見本片も名前も置かない。種類が揃う、という締めの定型文は足さない。材料に無いお得、最強、パーティと、手順は書かない。

絵。個品を描くテーマでは、対象の個品を全部出す。料理だけに限らない。文が片方でも、絵は全部。片方の個品だけは不合格。色、厚み、1片の大きさは、その単品で人が確定した見本だけが正。見本が無い構成は、黙って落とさない。

袋。袋を出すテーマだけ、各袋の縦横比と、袋どうしの大きさの対比を守る。片方だけ小さくしない。サブは描く方式のまま。メインの文面、字数、金丸、ペルソナ、後貼りは使わない。新しいテーマは作らない。

料理。商品が食品のときだけ。候補は、マスタに書いてある食べ方と、公式ページで調べた食べ方。新しい料理名は作らない。1テーマに1つ。テーマごとに別の食べ方。皿の上の個品は、ミックスの対象を全部出す。選んだ食べ方と別の食べ物は足さない。食べ方が無いテーマは、料理を空にして商品そのものを写す。メインの完成画像の構図は使わない。食品でないときは、この料理の候補を足さない。

合格は、生成前にこの規則を満たすかで見る。
