## 3. Catalog（準備メニュー・出品 clasp）

クォータは出品側。HTML スクレイプ禁止。`brandNames` 指定は正にしない。各段のあと **タイトルにメーカー名が含まれる** ものだけ残す。

本線は **A–E 全本を同時に回さない。** 階段:

| 段 | 内容 | 0件 |
|----|------|-----|
| A′ | identifiers（JAN/EAN） | → B′ |
| B′ | keywords=JAN | → D′ |
| D′ | keywords=メーカー＋商品名 | → E′ |
| E′ | keywords=短い核 | 打ち切り |
| C′ | AI商品名のみ | **診断シートのみ** |

ヒットは貼付ブロックの **ASIN 空欄だけ**埋める。既存 ASIN・◎は上書きしない。

Amazon A–E 全本は診断シート専用（マスタ非書）。楽天Yahoo ベイクオフと同じ位置づけ。

領域1の Catalog 全件成果の後読みは **任意のトークン節約**であり、本線の発見クエリではない。

## 5. 非候補化と並べ替え（Aのあと）

**禁止**: 行削除、評価列消去、◎の機械記入（A既存は聖域）、◎を空にしない。

**する**: `機械候補`＝候補／非候補＋理由。Keepa A が先に◎を書く運用では、**機械◎でも** ふるさと・選択式・中古・種類数なし各N袋・単価2倍・メーカー無しは非候補。人が直す前の精度用。評価の◎自体は残す。

単位は **1商品ブロックの縦**。隣ブロックと混ぜない。行を一体で動かす。

1. **上段＝候補**（◎でもタイトル非候補なら下段）  
2. **下段＝非候補**  

上段ソート:

1. 推定袋数の **昇順**（不明は上段末尾＝非候補の直前）  
2. 同一袋数内は **ヒット率の高い順**

**ヒット率**＝A 直後の **名前一致＋画像一致の総合評価**（現行 Keepa 評価スコア）。Catalog `hit_rank` は補助。Keepa 未取得行は非候補判定せず、「未属性」として上段末尾付近。

再実行で◎は消さない。再ソートしても◎は上段。
