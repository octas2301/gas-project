## 4. 社長決定（2026-07-20）

| 項目 | 決定 |
|------|------|
| マスタ「在庫数」書込 | **禁止**。在庫0/1はバルクファイル内の値のみ。楽天/Yahoo共有列への副作用を避ける |
| DONE定義 | **`GENERATED`（Drive生成）** と **`UPLOADED_OK`（Seller Central 処理レポート成功）** を分離 |
| M1着手ゲート | **GTIN免除承認**が必須。手作業1件テンプレ成功・画像URL方式確認は着手必須にしない（検収前§11） |
| Amazon候補抽出 | **親SKU単位**（案1）。同一親の承認済み子をまとめてバリエーションバルク生成（楽天と同型） |
| UPLOADED_OK記録 | **案B**: Lv4専用実行ログ／状態シートに `subBatchId` 単位。メニュー「アップロード成功を記録」。調査用ログ必須 |
