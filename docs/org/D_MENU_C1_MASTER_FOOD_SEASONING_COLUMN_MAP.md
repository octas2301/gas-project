## 4. 既定と安全

- **PT／Browse（2026-08-02改定）**: マスタ `Amazon Product Type`／`Amazon Browse Node` は **両方必須**。空なら親一式除外。**唐辛子等の json 既定で埋めない**（`p4b_require_master_pt_browse=true`）
- **許可PT**: `FOOD`／`SEASONING`／`HEALTH_PERSONAL_CARE`（`p4b_c1_product_types`）
- テーマ既定: **SEASONING複合**はテンプレ許容値に従う（従来`SET_NAME`可）。**缶飯／GROCERY（FOOD_FISH_GROCERY）**は純正プルダウンのみ（`サイズ`／`フレーバー`／`色`／`味/サイズ`）。缶飯本線=`サイズ`（`SET_NAME`はSCエラー）
- **GROCERY数量ポリシー**（`c1_quantity_policy`）: 入数・ユニット＝セット缶数（親総個数／一人分160禁止）、重量＝バリエ`N缶/xxxg`から解析（親総重量960禁止）、バリエ値は **ATの`size`**（`package_size_name`ではない）。色・商品形態・温度定格は黒セル対策で未出力
- ブランド=`ノーブランド品`
- ID種別=`GTIN免除`
- 温度: SEASONING等は`常温：室温`。GROCERYは未出力（保存方法長文を定格に載せない）
- 在庫=`0`
- タックスは固定せず、マスタ `商品タックスコード` を使用
- **商品の形式（134）はSC必須**。マスタ `商品の形式` があればそれ、無ければ既定 `ホール`（缶飯。旧・粉末既定は廃止）
- **メーカー型番**: マスタ `メーカー型番`（HJ）優先 → `メーカー品番`／`型番` → GENERATED `manufacturerPart` → 子SKU
- **ハイライト（100476）**: タイトル≤75のときのみ。優先 **楽天キャッチコピーAIから取得 → Yahoo!キャッチコピーAIから取得 → 箇条書き①**。タイトル76字超は空
- **商品の重量の単位（166）**: マスタ優先、無ければ既定 `グラム`（2026-07-31）
- **検索用キーワードは1枠のみ**（列39）。マスタキーワードを空白結合。`keyword2〜5` は書かない（SC 99016 対策・2026-07-31）
- **サブ画像（24〜31）はマスタ `Amazon PT URL` のみ**。GENERATED／楽天CDNへフォールバックしない（空なら空のまま）
- メーカー・原料・ユニット数／単位・原産国・箇条書きが空なら親一式除外
- `Amazon MAIN URL` 空も親一式除外

ブランド名・GTIN免除証跡はSC送信前に人間が確認する。
