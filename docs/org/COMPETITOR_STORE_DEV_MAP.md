## ポイント列（混同禁止）

- **楽天:** `pointRate`＝**％**。ポイント数ではない。
- **Yahoo!:** 単位は**未確定**（旧 `point.amount` は 0 固定。現行は `lyLimitedBonus*` の可能性）。いまの薄いパースでは Yahoo のポイントは列にほぼ載らない。
- 同一「ポイント」列の生値を足したり、％と円を混ぜたりしない。後で列名分割する可能性あり。

## モールヒット列が xlsx より少ない理由

**意図的。** `mall_keepa_field_crosswalk_tagged.xlsx` は3モール＋Keepaの**辞書**（カテゴリID・梱包・ランキング等を含む）。`モールヒット` は検索ヒット1行の**運用列**（キー・価格・送料フラグ・ポイント・URL・生JSON）。

揃えないもの: カテゴリID／ブランドID／ASIN のモール横断マージ、Keepa専用（梱包・FBA・csv時系列）。  
◎で後から使う分は **生JSON** に残す前提（薄いパースの列だけ昇格）。全列コピーはしない。
