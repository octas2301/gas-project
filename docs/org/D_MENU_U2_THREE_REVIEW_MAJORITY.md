1. ONLY PT 作業面＝**マッチング sheet 本線**。`02` 手置き＝例外・復旧のみ  
2. POC 旧「02＝人間が置く」を案α（sheet→GAS→02）に整合  
3. 実装承認に変更ファイル一覧＋楽天 R-Cabinet／D Strict **非退行**検収を必須  
4. モードは子SKU単位を優先できること（親一括だけでは不足しうる）  
5. 既存マトリクス制約の明文化（25列固定読み・`sheet.clear()` 再生成・枠の列位置・永続化）  
6. 白抜き候補の入力元を定義  
7. ファイル名キー＝`sellerSku`（通常＝子SKU）一本化
