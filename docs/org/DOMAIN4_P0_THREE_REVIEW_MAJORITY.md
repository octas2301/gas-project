## 3. 採用（2/3以上）

1. 現在庫P0既定＝シート再計算（`InventoryLogic.gs` 同規則）。GAS読取IFは C4不一致時の別承認。  
2. 再計算と C4 は「かつ」。C4 は ±0 必須。  
3. P0出口はローカルTSVのみ（作業シートは外す）。  
4. マスタ読取: 親行除外、セット数は数値セル前提、JAN／倉庫キー正規化、`skip_reason` 固定（名簿に無いキーは在庫0にしない）。  
5. 異常時 fail-closed。  
6. ミックス分解計算は P0 保留（P6）。P0 は skip。  
7. 聖域・非書込は現状維持。
