# 3者独立レビュー運用（RUNBOOK）

**文書種別**: 情シス／戦略企画の手順正  
**最終更新**: 2026-07-15  
**適用**: 組織憲章・承認マトリクス・重要要件の「3者検証＋多数決」  
**親文書**: [AI_ORG_CHARTER.md](AI_ORG_CHARTER.md) §9 ・ [PHASE0_THREE_REVIEW_MAJORITY.md](PHASE0_THREE_REVIEW_MAJORITY.md)

---

## 1. 基本方針（D: 起動文の正本化＋自動化）

| やること | やらないこと |
|----------|--------------|
| **親 Agent 1本**が子を最大3本・**別モデル**で**並列**起動 | 人間が New Agent×3 を開き、起動文を手コピペ |
| 子同士は**互いの結果を見ない**（独立） | 1本に「3役を演技」させる正式判定（簡易再レビューのみ可） |
| 親が回収し **2/3採用・1票は未決** の多数決案を出す | 子に正本を勝手に書き換えさせる（書き込みは社長承認後） |
| 起動文の正はこの RUNBOOK | チャットごとにプロンプトを再発明する |

人間の起動は短い指示だけでよい（例: 「Phase0の3者レビューを実行」「この憲章改定の3者レビュー」）。  
親は **本ファイルを読んで** 下記プロンプトで子を起動する。

---

## 2. 親がやること（チェックリスト）

1. 対象 docs を特定する（既定: 憲章＋マトリクス＋ `AGENTS.md` §2/§5/§8＋必要なら `CURRENT_PHASE.md`）。  
2. Task／サブエージェント等で **最大3本・別モデル**を並列起動し、§3 の子プロンプトを渡す。  
3. 子の完了を待ち、§4 形式で多数決メモ案を書く（新規なら `docs/org/` 配下、ファイル名は案件に応じて）。  
4. **docs への書き込み・commit** は社長承認後のみ。コード実装は Phase0 対象外なら禁止。  
5. モデルが3系統揃わない場合は、可能な別系統で埋め、メモに「独立性の弱さ」を注記する。

---

## 3. 子エージェント用プロンプト（正・コピー元）

親は各子に次を渡す。`Reviewer-N` とモデル名だけ差し替える。

```text
【役割】
あなたは独立レビューア（Reviewer-N / 使用モデル名を自己申告）です。
新規構想の勝手な拡大は禁止。既存ドキュメントの検証のみ。
コード・新ファイルは作らない。他レビューアの結果は参照しない。

【必読（この順）】
1. docs/org/AI_ORG_CHARTER.md
2. docs/org/AI_APPROVAL_MATRIX.md
3. AGENTS.md の §2（聖域）・§5（レビュー観点）・§8（Cloud注意）
4. docs/CURRENT_PHASE.md（スコープ確認）
（追加指定があれば親の指示に従う）

【採点（各1–5＋根拠を2行以内）】
1. 実現性
2. 要件漏れ
3. 矛盾
4. 聖域
5. 逃げ漏れ（要実機・未決の明示不足）

【出力形式（厳守）】
## レビューアID
Reviewer-N（モデル名）

## 総評
（3行以内）

## スコア表
| 観点 | 点 | 根拠 |

## 必須修正（採用推奨）
- …

## 任意改善
- …

## 未決として残すべき事項
- …

## 結論
YES / NO / 条件付き（条件を1～3個）
```

観点の詳細は憲章 §9 および案件ごとの補足に従う。

---

## 4. 親の多数決出力（正）

```text
## 多数決メモ案
### レビューア一覧（モデル・結論）
### スコア表（3者）
### 採用（2/3以上）
### 未決（1票または割れ）
### 社長に確認したい質問（最大3）
### 総合: YES / NO / 条件付き
```

採用したものだけ正本差分案を示し、**承認前にファイルを書かない**（または書き込み前に明示承認を取る）。

---

## 5. 人間の最短起動文（任意・記憶用）

コピペ不要が理想。どうしても貼る場合:

```text
docs/org/THREE_REVIEW_RUNBOOK.md に従い、3者独立レビューを実行。
親が子を最大3本・別モデルで並列起動し、互いの結果を共有させない。
完了後に多数決案のみ提示。docs書き込みとコード改修は承認後／禁止に従う。
```

---

## 6. 簡易モード（例外）

時間がない・軽微な文言修正のみのとき、親1本に「Reviewer-1/2/3を**順に**書き、途中で自己参照して結論を変えない」を許可する。  
正式な Phase 完了判定には使わない。メモに `mode: pseudo-triple` と記す。
