## 1. 消去の2パターン

### 1A. 行ごと消す（推奨・原因追及向き）

対象商品の **親行＋子行ブロックを丸ごと削除** し、AIキューから Step1 で再挿入する。

| 手順 | 操作 |
|------|------|
| 1 | 再実行したい商品の **親SKUブロック**（親1行＋子すべて）をマスタから削除 |
| 2 | 対応する **AI情報取得data** 行の **`B済` を空**にする（同じ行を再パックさせる） |
| 3 | （任意）`▼B実行サマリ` の旧 runId は残してよい（比較用） |
| 4 | B統合を **新規** 起動（続きダイアログは **いいえ** または state 削除） |

**残す**: ASIN貼付の **◎**、競合DB、テンプレ1–2行、設定シート。

### 1B. 行は残して列だけ消す（部分再実行）

行削除が難しいとき。**§2「消す列」** だけ対象行でクリアし、Zメニューから該当Stepを単独実行、またはB統合を新規起動（Step1はスキップ相当になるので、通常は **1A推奨**）。

## 2. 列単位チェックリスト（8行目ヘッダ名＝正）

字母（B,C,…）は **2026-08-13 時点**。列挿入後は **ヘッダ名で判断**する。

### 2.1 絶対に消さない（聖域・人間確定）

| 区分 | 列（ヘッダ名） | 理由 |

## 3. 人間の実行手順（推奨順）

```text
1. clasp push（出品）
2. Script Properties 確認（B_WATCHDOG_ENABLED=false）
3. 対象を決める（出品CK付き10親 等）
4. §1A: マスタから親+子ブロック削除
5. AI情報取得data の B済 を空
6. （推奨）単品親だけ AI行を並べ直し → B 1回目
7. ミックス親だけ → B 2回目（構成単品がマスタにあること）
8. 必要なら先にメニューA（Keepa）→ ⑥N列再テスト
9. B統合「新規」起動（続きは「いいえ」）
10. 完走後 §4 で合否判定
```

**B state リセット**: 続きダイアログで **キャンセル**（`deleteBIntegratedState`）または **いいえ**。

**色だけ直す**: Z→15-㉒（11〜775）。データ再生成の代替にはならない。
