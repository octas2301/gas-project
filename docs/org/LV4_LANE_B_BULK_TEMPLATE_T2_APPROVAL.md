## 1. 目的

**棚に無い型（PT＋指紋）**、または **現行登録マップでは必須列が埋まらない**ときだけ、次を本線化する。

1. SC純正（**別系統の複合** or 単体）を **09→B-T0→06** で棚登録  
2. **`shelf_registry.json` に PT＋指紋**を追加  
3. **項目名エイリアス**（必要なら column_map プロファイル）を整備  
4. 以降は B-T1 と同じく **棚引き → dry_run／prod**（同型なら再DL不要）

| 段階 | 内容 | 状態 |
|------|------|------|
| B-T0〜T1 prod | 当面 SEASONING＋複合（`FOOD_HERB_SEASONING_…`） | **済**（棚の現本線の1つ） |
| **B-T2（本包）** | **別複合／新PT／単体**の棚登録＋本線化 | **方針ロック済・実装は実需後** |

## 2. 背景（社長確認の定義・2026-08-01）

- 今後も複数商品を登録する際、**カテゴリに応じた複合バルクをDLして棚に載せる**  
- **いまのシーズニング用複合＝全複合の定義ではない**（複合ファイルは複数あり得る）  
- **該当するブラウズノード／系統の純正が既に棚登録済みなら、新しいバルクのDLは不要**  
- **Amazonがマスター（純正テンプレ）を変えたとき**は指紋が変わるため **再DL・棚更新が必要**  
- 機械の **充填可否**の正は **PT＋テンプレ指紋（sha）**。**どのテンプレ／採用PTか**のルーティングは Browse Node ID 網羅カタログ（[SHELF Browse](LV4_SHELF_BROWSE_CATALOG_APPROVAL.md)、2026-08-02）  
- `HERB.xlsm` 単体は **自動本線化しない**（複合で足りるなら単体は任意保管）  
- 七味停止中／48h審査とは独立

## 4. 社長確定方針（**ロック済 2026-08-01**）

| # | 論点 | **決定** |
|---|------|----------|
| 1 | 複合の定義 | **複合は複数あり得る**。`FOOD_HERB_SEASONING_…` は当面の SEASONING 本線の1つであり、全商品共通の唯一複合ではない |
| 2 | 起動条件（B-T2） | **レジストリに当該 PT＋指紋が無い**、または現行マップで必須列が埋まらないときのみ |
| 3 | DL不要 | 棚に **同型（PT＋指紋）が登録済み**なら再DL不要（ブラウズノードが同じ系統でも、機械OKは指紋一致が正） |
| 4 | DL必要 | (a) 棚に無い系統の複合／単体が要る (b) **Amazonが純正を更新**して指紋不一致 |
| 5 | 第一候補 | **複合優先**。載っていれば単体xlsmを増やさず複合＋当該PTで充填 |
| 6 | 単体xlsm | 複合に無い／運用不能なときだけ 09→T0→06 |
| 7 | `HERB.xlsm` | **自動本線化しない** |
| 8 | レジストリ | エントリ単位は **PT＋sha**（カテゴリ名の曖昧一致で自動OKにしない）。**ルーティング**は [SHELF Browse 網羅](LV4_SHELF_BROWSE_CATALOG_APPROVAL.md) の **browseNodeId**（2026-08-02 昇格）。機械の最終検証は従来どおり PT＋指紋 |
| 9 | エイリアス | 既存 aliases 流用優先。列番号の新規焼き直し禁止 |
| 10 | defaults／必須 | PTごとに分離可 |
| 11 | 在庫 | Dの `inventoryMode` 継承。B-T2で変えない |
| 12 | モード | dry_run → prod（T1／prodゲート継承） |
| 13 | 聖域 | 06破壊禁止・03上書き禁止・マスタ非書込・SC自動ULなし・楽天／Yahoo／B統合非触 |
| 14 | 実装タイミング | **実需PTが決まってから実装承認**。方針ロック時点ではコード着手しない |
| 15 | 三点 | **スキップ**（2026-08-01） |

## 5. 定常フロー

```text
① P4b等で PT／browse 決定（人間）
② shelf_lookup（PT＋登録指紋）
     ├─ DL_NOT_NEEDED → B-T1 のまま（B-T2不要）
     └─ DL_REQUIRED
          → 人間: 必要なら「別系統の複合」または単体を SC から DL → 09
          → B-T0 → エイリアス → 06＋registry
          → B-T1 dry_run／prod → 人間が SC UP
（別途）Amazon純正更新で指紋不一致 → 再DL→棚更新
```
