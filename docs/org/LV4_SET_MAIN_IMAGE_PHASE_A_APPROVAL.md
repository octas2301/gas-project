# セットMAIN画像 Phase A — 承認パッケージ

**状態**: **実装済**（2026-08-02・社長実装承認）。スモーク（`--smoke-amazon`／`--smoke-rakuten`）OK。実素材での本出品品質は社長判定。  
**手順**: [D_MENU_SET_MAIN_IMAGE_PHASE_A_HUMAN_RUN.md](D_MENU_SET_MAIN_IMAGE_PHASE_A_HUMAN_RUN.md)  
**ツール**: `tools/set_main_image/`（`compose_set_main.py`）  
**三者**: **スキップ**（実装承認時）

---

## 1. 目的

Canva でセット数ごとに手作業している MAIN 量産を、人間が作った **1個セット素材**から機械合成する。

| モール | やり方 |
|--------|--------|
| **Amazon** | 大1＋小を横／重ね／グリッド。食品は **Octas必須**（商品右下に重ね） |
| **楽天／Yahoo** | **同一テンプレ**。金丸デザイン固定、**数字のみ**差し替え |

**やらない**

- ~~N=1 の生成（Canvaのまま人が置く）~~ → **2026-08-09: N=1もツール生成対象に変更**
- 1個セットのAI生成（Phase C）
- Canva API 必須連携
- SC／RMS／Yahoo への画像自動UP
- 生成AI（Phase A は **Pillow 合成のみ**）

## 3. 入出力（ロック）

### 3.1 サイズ

| モール | 出力 | 入力1200のとき |
|--------|------|----------------|
| Amazon | 目標 **2000×2000** | 拡大してよいが、元が1200なら実質メリット薄 → **1200のまま出力して可** |
| 楽天／Yahoo | **1200×1200** | 現行どおり |

比率: **正方形 1:1**。

### 3.2 入力

| 入力 | 仕様 |
|------|------|
| 1個セット素材 | 人間（Canvaベース）。**N=1もツールで金丸数字合成**（2026-08-09〜） |
| 対象 | マスタの **セット構成（親配下の子SKU＝セット行）** から一括 |
| `set_count` | 各子行のセット数（例: 3/10/30） |
| `mall` | `amazon` および `rakuten`（Yahooは楽天と同一処理） |
| 食品判定 | マスタ **T列**「カテゴリー ※食品のみ入力でOK」。値に **「食品」が含まれる** → 食品（Octas必須）。空／非食品 → Octasなし |
| Octas | **全食品共通1枚** PNG。**商品（ヒーロー）右下に重ねる** |
| 楽天／Yahoo数字 | **(a) 数字別レイヤ**（金丸デザインは変更不可。数字だけ差し替え） |

### 3.3 出力・運用接続

| 項目 | 仕様 |
|------|------|
| 置き場 | **Drive `05.画像生成（セットMAIN）`**（01 Amazon／02 楽天／97数字任意／98金丸任意／99 Octas）。合成結果は **07**（C接続） |
| 命名 | **子SKU（セット行）基準** `{childSku}_{mall}.jpg` |
| 楽天数字 | **書体カタログ `--font-id`**（本線）。97数字レイヤは位置ガイド任意 |
| 実行単位 | **一括**: 指定親について、セット行の N 群×モールを一発生成 |
| 想定規模 | 週 **2親 × セット約10種 ×（Amazon＋楽天）＝約80枚** |

## 4. Amazon プリセット（ロック）

| 規則 | 内容 |
|------|------|
| 選択 | **Nから自動**（手動必須にしない） |
| 小商品 | **完全コピー**（閉缶差し替え等なし） |
| 影 | **なし** |
| 背景 | 基本白。パッケージ一部画像の挿入は将来（v1は白＋商品合成） |

自動選択案（実装初期値・微調整可）:

| N | preset |
|---|--------|
| 2〜6 | `hero_row` |
| 3（任意優先） | `hero_pyramid` 可 |
| 7〜15 | `hero_stack` |
| ≥16 | `hero_grid` |

（ツール対象は N≥2のみ）

## 5. 楽天／Yahoo バッジ（ロック）

| 項目 | 決定 |
|------|------|
| Yahoo | 楽天と **同一** |
| 変更 | **数字のみ**（単位・「セット」等の文言は1個セット踏襲・変更なし） |
| 金丸 | デザイン変更不可 |
| 実装 | **(a) 数字別レイヤ**（座標JSON塗りつぶし方式は不採用） |

1個セット用の Canva から、機械用に **数字なし土台**（＋必要なら数字レイヤ書き出し）を用意する運用とする。

## 6. 実装順（ロック）

1. **Amazon コラージュを先に**本出品品質まで固める  
2. **続けて楽天／Yahoo**（数字レイヤ差し替え）も同 Phase A でやる（「Amazonだけ作って終わり」にはしない）  
3. 本開発として進めるが、**出品OK品質に届かなければリサーチへ切替**してよい
