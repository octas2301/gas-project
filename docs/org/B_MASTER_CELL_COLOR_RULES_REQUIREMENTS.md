## 1. 層構造

```text
L0 行識別 …… 親行地色のみ（子行地色は付けない）
L1 意味   …… 黄／緑／ピンク／灰（＋オレンジは必要時）
L2 必確認 …… 濃赤＋白文字（セル）
```

### 1.1 優先順位（衝突時）

1. **L2 濃赤＋白字** — そのセルでは最優先で見せる  
2. **L0 親水色** — **行全体の塗り**としては最強。親行を緑／ピンク／灰などで塗り潰さない  
3. **L1** — セル単位。親水色の上に黄・緑・ピンク・灰・（必要時オレンジ）・濃赤を載せてよい

## 2. パレット（役割）

| 記号 | 役割 | HEX | 適用単位 | ⑧c |
|------|------|-----|----------|-----|
| **親水色** | 親SKU行の識別 | `#ADD8E6` | **行全体（B〜JY）** | `MASTER_COLOR_PARENT_ROW_` |
| **黄** | **人間が触る**（入力・選択・見て修正） | `#fff2cc` | 子セル | `MASTER_COLOR_HUMAN_` |
| **緑** | 上流確定をPGが転記（再確認しない） | `#d9ead3` | 子セル | `MASTER_COLOR_PROGRAM_` |
| **ピンク（上書き）** | プログラムが **後から上書き**した | `#f4cccc` | セル（段階） | `MASTER_COLOR_OVERWRITE_` |
| **親・赤白チェック** | 親のみ必確認（レ点青字可読） | `#f4cccc`（**白字にしない**） | 親の指定セル | `MASTER_COLOR_PARENT_CHECK_` |
| **灰** | 式／転記／触らない | `#eeeeee` | 子セル | `MASTER_COLOR_SKIP_` |
| **白** | 未使用／親のみ（子は空）／削除候補 | `#ffffff` | 子セル | `MASTER_COLOR_WHITE_` |
| **オレンジ** | ソフト警告（壊れてはないが注意） | `#fce5cd`（仮） | セル（任意） | **後回し・未定数** |
| **濃赤＋白字** | エラー（利益不足等） | 背景 `#8B0000`／文字 `#ffffff` | セル | `MASTER_COLOR_ALERT_*` |

**注意**: 親・赤白チェックと上書きピンクは **同HEX `#f4cccc`**。親行の指定列＝赤白チェック、子の上書き＝ピンク、と文脈で区別する。濃赤＋白字はエラー専用（赤白チェックに使わない・レ点青字が潰れるため）。

**適用範囲**: **B〜JY**（col 2–285）。**JZ（⇒AI作業エリア）以右は色なし**。

**条件付き書式**: 既存ルールの色・条件は **変更しない**（GASの `setBackground` のみ役割色を付ける）。

役割の変更は本正本の改訂が必要。

## 3. 用語定義

| 用語 | 定義 |
|------|------|
| **親行** | 子SKUが空の行。地色＝水色 |
| **子行** | 子SKUがある行。**地色は付けない**（旧ピンク地は非公式） |
| **黄** | 人が入力する／選択する／見て修正する場所。自動要確認（N列ASIN・競合ASIN・自社品番等）も含む |
| **緑** | プログラムが埋めた値。人の作業キューに載せない目印（段階導入） |
| **ピンク** | 既存の値・式・前回結果を、後続プログラムが差し替えた目印 |
| **灰** | 処理対象外・スキップ・除外（例: 箱 `exclude`、今回触らない塊） |
| **オレンジ** | ソフト警告（文字数ぎりぎり、信頼度低など）。濃赤ほど致命ではない。**必要時に追加** |
| **濃赤＋白字** | エラーまたは業務上必ず見てほしい |

### 3.1 黄についての運用（Q4確定）

- 理解: **黄色＝人間が入力するところ、見て修正するところ**  
- **確認後に色を変更しなくてよい**（必須のクリア運用はしない／手間増を避ける）  
- `要確認_*` 列や note は任意で残してよい（色クリアの代替にはしない）  
- 人入力列の常時黄も **消さない**（欄の役割表示）

## 4. 意思決定フロー（付色時）

```text
1. 親SKU行か？
   → 行地色は必ず水色。行全体を他色にしない
2. エラー／必確認か？
   → 濃赤＋白字（L2）
3. スキップ／対象外か？
   → 灰（D1）
4. ソフト警告か？（必確認ほどではない）
   → オレンジ（D2・必要時のみ。現状スキップ可）
5. 人が触る／見て修正するか？
   → 黄
6. プログラムの後追い上書きか？
   → ピンク
7. プログラムが書いただけか？
   → 緑（段階導入の対象なら）
8. どれでもない
   → 色を付けない（親なら水色のみ）
```

## 11. 基本ロジック（⑧f 確定・メモ）

```text
1. 範囲は B〜JY。JZ以右は塗らない。条件付き書式は変更しない。
2. 親行（子SKU空）:
   - 既定 = 水色 #ADD8E6
   - 例外列（§12 親・赤白）= #f4cccc（文字色は白にしない＝レ点青字可読）
3. 子行（子SKUあり）:
   - 式／モール転記／触らない = 灰 #eeeeee
   - 人が見る・直す = 黄 #fff2cc
   - 上流確定のPG転記（再確認しない）= 緑 #d9ead3
   - 未使用／親のみ入力／削除候補／タイトル親継承 = 白 #ffffff
4. エラー（利益不足等）だけ濃赤＋白字。親の必確認には使わない。
5. 上書きピンクは「後から差し替えた」目印（子）。親赤白と同HEXだが用途が違う。
```

実装: `コード.js` の `MASTER_COLOR_*_LETTERS_`／`masterColorApplyLockedRow_`／`masterColorApplyLockedRows_`。  
Step1（セット構成）はブロック追加時にロック表で塗る。再適用は Z→15-㉑（選択）／15-㉒（11〜775）。

## 12. ロジック外指定（列ロック・ヘッダ名メモ）

列字母は **2026-08-13 時点のマスタ8行目**。列挿入時は字母がずれるため **ヘッダ名を正**とし、コードの字母リストを更新する。

### 12.1 親・赤白チェック（親のみ／必確認）

| 列 | ヘッダ（要約） |
|----|----------------|
| R | 区分 |
| S | メーカー・問屋半角英字 |
| T | カテゴリー ※食品のみ… |
| CQ | サイズ＆自己発/FBA |
| GN–GQ | バリエーション接頭辞／単位／1個当たり内容量／接尾辞 |
| HU–HV | バリエーションテーマ／テーマ2 |
| IF | 原産国/地域 |
| IR–IS | 楽天ジャンルID／名 |
| IZ–JD | 指定セット〜Yahooブランドコード（IZ,JA,JB,JC,JD） |

### 12.2 子＝白（親のみ・未使用・継承想定）の主な例外指定

- Q,R,S,T,X,Y（購入日／区分／接頭辞／食品カテゴリ／自己発送／賞味期限）  
- CQ, IF（親のみ書込）  
- DF,EE,EY は **灰**（計算式）← 白ではない  
- FH–FK, GU, GX, GZ, HJ, HN, HQ, HT–HV, IR–IS, IZ–JD  
- タイトル作業・最終名など親継承想定列（FS–GA 等は白寄り。詳細は字母リスト）  
- BD–BI 出品者SKU画像URL（未使用・削除候補）  
- **AZ・BA・BB は灰リストから除外**（2026-08-16。構成列再利用。子の既定は白）  

### 12.3 子＝灰（式）の代表

HW バリエーション値、HX 子SKU、IB 親SKU、HL メーカー型番、在庫・価格転記式、GN–GQ（子は式コピー想定）等 → `MASTER_COLOR_CHILD_GRAY_LETTERS_`

### 12.4 子＝黄／緑の代表

- 黄: C 出品CK、N/O/P ASIN・競合、価格 DE/ED/EX、CP/CS、競合価格 等  
- 緑: G メーカー名ベース、K 卸値(税抜)、CW/CX、FN  

完全な字母配列は `コード.js` の `MASTER_COLOR_CHILD_*_LETTERS_` が正。

## 13. 列を追加したとき（エージェント／人間への聞き方パターン）

新しい列をマスタ（B〜JY）に足す・ヘッダを変えるときは、実装前に **次をパターン分けして質問**する（勝手に色を決めない）。

| # | 質問 | 選択肢（例） |
|---|------|----------------|
| A | **親子どちらに書く？** | 親のみ／子のみ／両方／式で子←親 |
| B | **誰が確定する？** | 人がマスタで確認（黄）／上流で確定済みPG転記（緑）／式のみ触らない（灰）／未使用・削除候補（白） |
| C | **親の必確認か？** | はい→親・赤白 `#f4cccc`（子は通常白）／いいえ |
| D | **エラー時に濃赤白字が要るか？** | はい（例外）／いいえ（通常は赤白チェックか黄） |
| E | **JZ以右（AI作業）か？** | はい→色なし／いいえ→B〜JYロックに追加 |

回答を §12 と `MASTER_COLOR_*_LETTERS_` に追記してから塗色・Step1反映する。  
列挿入で字母がずれた場合は、**ヘッダ名で突合して字母リストを再生成**する。
