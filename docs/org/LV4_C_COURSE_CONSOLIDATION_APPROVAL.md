## 3. スコープ

### 3.1 含む

| 項目 | 仕様 |
|------|------|
| メニューIA | トップは **`C. 画像コース（選択可）` 1項目**。D型モーダルから工程を選択。C-0〜C-2とC-Amazon①〜④は **Z互換**へ移動（削除しない） |
| C-0 | 前提チェック（U2 Property・07フォルダ・レ点／sheet一致の案内）。E-0相当の画像部 |
| C-1 | マトリクス生成（現行 `generateAiImageMatrix`）＋ Amazon時は①②相当（枠・候補）。成功時は toast 可・不要なOK連打は避ける |
| 【人間ゲート】 | Drive **07** へ白抜き配置 ／ マッチングsheetで **MAINドラッグ**（ONLYならPT）。**自動化しない** |
| C-2（Amazon新規） | ③→④→**U4**（既存 E-2 相当）。**開始前確認**。U2/U4は実行中一時ON→復元 |
| 楽天のみ | C-1中心。U4・Amazon②④は実行しない |
| E-1/E-2 | Cコース呼出に寄せる。D補助の旧Eは案内または薄い互換ラッパ |
| レ点契約 | U2どおり維持（子レ点＝その子のみ／親のみ＝全子）。変更しない |
| 安全停止 | sheetと現在レ点不一致時は候補配置・③④相当で停止（現行維持） |
| Property | C本線は U2/U4 **一時ON→復元**。常設は07フォルダID。Z単独は従来ゲート |
| docs | HUMAN_RUN（Cコース）／本承認／CHANGE_LEDGER／CURRENT_PHASE／E・U2 HUMAN_RUNの入口更新 |

### 3.2 含まない

- MAINドラッグ自動化・白抜き自動生成  
- P1（07以降 File最少のパイプライン変更）  
- U5 ZIP自動化・Dc・P4a  
- 楽天画像マッチングアルゴリズムの大改修  
- マスタ「在庫数」／JAN への書込  
- U2/U4 の**常設 true 放置**（実行後は必ず復元）  
- ALLOW_PROD 等の出品系トグル自動ON  

### 3.3 P1との境界

| 本承認（C-IA） | P1（別承認） |
|----------------|--------------|
| メニュー／クリック削減 | 07→02／退避／File手数の自動化寄り |
