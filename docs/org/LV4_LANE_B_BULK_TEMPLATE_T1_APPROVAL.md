## 5. 定常作業フロー（契約）

```text
① スプシ: カテゴリ／PT（P4b 等）を決める
② 棚引き: 登録済み（PT＋指紋）が 06／レジストリにあるか
     ├─ あり → 「DL不要」→ 06 の純正をコピーして充填（③へ）
     └─ なし → 「09へSC DL要求」→ 人間が09へ保存
                → B-T0 指紋 →（必要なら別名整備）→ 06＋レジストリ登録
                → ③へ
③ 項目名マッピングで dry_run 充填 → 03／05
④（別承認後）prod → 人間が SC UP
```

### 5.1 マッピング解決（各論理キー）

```text
論理キー → xlsm 項目名候補 → 列番号を実行時解決 → 書込
不一致 → 不足一覧（必須なら親除外）
```

### 5.2 入力の出所

| 出所 | 例 |
|------|-----|
| マスタ | メーカー、箇条書き、タックス、原産国、URL、原料、定価、梱包… |
| GENERATED | sellerSku、価格、親子 等 |
| defaults | PT=`SEASONING`、browse（P4b許可時はマスタ優先可）、ブランド、粉末 等 |
| 書かない | マスタ空かつ非必須 |

### 5.3 行構造

- サンプル／注記行は保持  
- **縦**（開始行）は契約で固定可／**横**（列）は項目名のみ
