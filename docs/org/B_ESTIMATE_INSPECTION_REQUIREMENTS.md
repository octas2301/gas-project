### 1.1 希望価格（要望価格）の式と理由

正は品番リストの式（移さない）。`見積検品` の希望は計算結果の数字だけ受ける。**問屋に返す上限＝目標利益が残る仕入**。

1. 目標セット利益 ＝ `max(最安値×15%の切捨て, 200円)`（定数は品番リスト3行目）  
2. 最低利益（1個） ＝ 目標セット利益 ÷ セット数量  
3. 1点販売額 ＝ 最安値 ÷ セット数量  
4. 1点FBA手数料 ＝ FBA手数料 ÷ セット数量  
5. 目標仕入額（税込） ＝ 1点販売 − 1点FBA − 最低利益1個 − 販売手数料セット÷数量 − 保管セット÷数量  
6. 希望価格（税抜） ＝ 税込 ÷ (1＋税率)  
7. 販手・保管・FBAのいずれかが空の行は希望を空（事実が揃うまで出さない）

理由:

- **200円（セット）**: 発送作業＋梱包の平均が約80円のため、その上を残す  
- **15%**: 定期約5%＋広告約8%の余裕  
- FBA利益（売値−仕入−販手−FBA−保管）と希望の引き方を揃える（2026-11-15）

### 1.2 提示価格の二段運用（2026-11-13）

| 優先 | 内容 |
|------|------|
| 1 | 自社下限。セット利益 `max(最安×15%切捨て, 200円)` は切らない。**200円は切り下げない** |
| 2 | セット（2袋以上）で、希望仕入だと利益率≥30%なら安すぎ。提示を上げて利益率を30%未満（着地約29.9%）にする |
| 3 | 上げると下限を割るとき（多くは**200円下限だけで利益率30%超**）は、提示＝希望のまま。印「200円下限のため利益率30%超。上乗せ不可」。安すぎは許容 |

単品（1袋）には30%ルールを掛けない。提示＝希望。

## 2. 利益

本線は FBA。推奨と対象セットは、同じ袋数なら**売値が一番安いカタログ**の FBA利益で揃える。利益が最大のカタログは取らない。

FBA利益 = 売値 − 仕入 − 販売手数料 − FBA送料 − 保管（1か月）。

販売手数料（食品）: 売値750円以下は5%、1500円以下は8.4%、それ以外は10.4%。円は四捨五入。

利益がある、の線は **100円以上**。

仕入の袋単価（石原で通した値。他メーカーはメールの袋単価を同じ式に入れる）:

- 食べるおだし（かつお50g、まぐろ35g、ぶり40g）は 324円
- チーズかつお、まぐろチーズは 615円（見積のボリューム単価。条件でさらに1割引かない）

除外: タイトルが業務用・お徳用・kg、または500g以上。これを1袋の仕入で割ると、利益が数千円になる。

順位は食品全体の大カテゴリー。6万位を超えるカタログは対象セットに出さない。順位が無いカタログも出さない。

## 3. 月販と仕入袋

同じ大カテゴリー順位は、1商品。販売数は1つ。

1. その順位の袋のどれかに、Keepaの月販があれば、その最大を使う（利益が無い袋の月販も含めて探す）。
2. 全部空のときだけ、食品の順位からの推計。推定月販 ≒ 2.2 × 8,900 × 順位の −0.75乗。1未満は1。順位が無いときは推計しない。
3. 推計は、利益が100円以上のセットにだけ使う。
4. その販売数を載せる先は、利益が100円以上のうち、売値が一番安い1セット。
5. 仕入袋（点数）＝ 販売数 × **その行の商品の入数**。
6. 見込利益 ＝ 販売数 × そのセットのFBA利益。袋数はもう掛けない。

入数:

- 単品は、セットの袋数全部。
- ミックスは、タイトルの「各N袋」のうち、その行の味だけ。かつお＋まぐろ＋ぶりが各1袋なら、まぐろの行の入数は1。合計3袋をまぐろの仕入にしない。
- 「各N袋」が無く、味が1つだけタイトルにあれば、その1回分を入数にする。

同じ順位で選ばれなかった、利益のある袋は、推奨の参考に「同順位のため本線に含む」と書く。月販は足さない。

仕入可否:

- 可: 上の点数と見込利益がどちらも0より大きい
- 月販不明: 利益は100円以上あるが、順位も月販もなく、点数が出ない
- 手数料不明: 利益100円以上のセットが無く、カタログに手数料欠落がある。**見送りにせず**、可否と判断のセルをアラート色にして人に知らせる
- 見送り: 利益100円以上のセットがなく、手数料も揃っていて判定できる

条件が仮でも、仕入可否は通常価格のまま。条件の数字は判断に足さない。

回収（追記）:
- 判断列・手数料不明アラート: `estimate_inspection_apply_judge.py`
- 検討ASINの月販・順位: `estimate_inspection_kentou_asin.py`（索引行のASIN一致を確認してから転記）

## 4. 特別条件

条件文は貼付sheetの取引条件。文に「仮」とあるあいだも、増分は出す。仕入可否には使わない。

条件後の利益:

- おだし（袋単価324円）: 仕入を1割引、FBA送料の上限は252円
- チーズ（袋単価615円）: 仕入は615円のまま（すでにボリューム単価）。FBA送料の上限は430円

見せ方は、条件後の合計ではなく、**通常からいくら増えるか**。

- 利益が100円以上のセット数: 通常 → 条件後（差）
- 仕入目安: 通常の袋 → 条件後の袋（差）。差を N列へ
- 見込利益: 通常 → 条件後（差）。差を O列へ
- 新しく100円以上になったセット名
- 本線が動いた理由。月販が同じなら「月販はそのまま。利益が上がった分だけ見込利益が増える」。別の順位で初めて100円以上になり、その順位に月販があるときだけ、仕入袋が増える

同じ順位の中で、条件後に売値がより安いセットへ販売数が移っても、月販は1つのまま。袋は増えない。

N列の 0 は空欄ではない。仕入袋が増えない、という意味。

## 6. 表示

推奨の本線は、§3で選んだセットだけ。売値、利益、月販（実測か推計か）、入数、点数、月利、経路はFBA。

ミックスで入数がセットの合計より小さいときは、「セット○袋のうち入数○」と書く。

対象セットは、利益が無くても袋を出す。選ばれた袋は月販または月販推計。同じ順位で選ばれなかった袋は「月販-（同順位）」。それ以外で月販が無い袋は「月販-」。順位の表示は大カテゴリーだけ。

月販想定には、本線の販売数と点数に加え、Amazonの口コミ件数の合計を出す。
