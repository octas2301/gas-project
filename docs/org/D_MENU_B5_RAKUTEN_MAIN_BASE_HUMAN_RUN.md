5. **いまの親で良さそうな案を複数チェック**。提案キャッチ・セールス・ペルソナ・場面・訴求度（食品なら料理とソースURL）を見る。途中切れ・訴求の被り・方向が弱いときは、**残す案はレ点したまま／直す案はレ点を外す**→各案の「再作成するときの訴求軸」で候補を選ぶ（または自由入力1行）→「レ点を外した案を再作成する」。軸は他案と被らないものだけ選べる。戻るでは全作り直ししない。親を完了して次へ（先の親のチェックは保持）。採用画像は最大でレ点子SKU数

10. 採用した各カードで、**出品CKレ点子SKU**（表示例: `ishi-…-3（3セット）`）を複数チェックして割当
