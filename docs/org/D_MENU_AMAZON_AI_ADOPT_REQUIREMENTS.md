## 不変列（聖域）— 商品名ベース

**規則（確定）**: **`商品名ベース` は可変不可。読取のみ。**

| 操作 | 可否 |
|------|------|
| ジャンル／Yahoo 検索クエリ等への参照 | **可**（読取） |
| 最終名プレビュー用の seed 読取 | **可**（読取。FO があるときは二重計上しない） |
| 文字数 trim（末尾ワード削除） | **禁止** |
| 横断 dedupe／類似除去によるセル書込 | **禁止** |
| KW区切り正規化（`,`／`、` → 半角スペース等） | **禁止** |
| 空欄への候補採用・上書き・クリア | **禁止**（メニュー8は触らない） |

- 実装: `amazonAiHeaderIsProductSeed_`／`AMAZON_AI_ADOPT_TRIM_ALLOWED_LOGICAL_`（商品名ベースは trim 対象外）／trim 対象組み立てで product seed を除外。
- 併せて **FO（合計を除く商品名）／メーカー名／メーカー品番** も trim・正規化の書込対象にしない（v1.13）。
- **既往障害**: `trimBack letter=J 商品名ベース`（FO＋商品名ベース二重計上時）。復旧は版履歴で 7.5／7.6 前に戻してから再実行。

## 文字数（v1.13）

| モール | 上限 | 下限ブレーキ |

| 楽天 | 120 | 115 |

- FO（合計を除く商品名）があるとき、プレビューにメーカー名／商品名ベースを入れない。
- trim対象は検索KW・補足・特徴・用途・CTR・メインのみ。
- 判定は最終名セルの**表示値**を優先。
