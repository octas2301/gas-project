## 1. ① シリーズID（セット数揃え）

| 項目 | 内容 |
|------|------|
| シート | `AI情報取得data` **G列** |
| ヘッダー | **`シリーズID`**（旧 `JANコードorオリジナルカタログ商品名` をリネーム。JAN正はC列） |
| 人間 | 同シリーズ行に同じ文字列を入れる |
| Step1 | 同一 `シリーズID`（2行以上）のセット数を **和集合**で揃え、再OKダイアなし |
| 空 | シリーズID空は従来どおり行ごと独立 |
| H列 | **`ASINコード` のまま**（Step5列8／同期突合） |

トグル: `B_SERIES_ALIGN_ENABLED`（未設定=true）

---

## 2. ② メーカー辞書

| 項目 | 内容 |
|------|------|
| シート | `00_設定マスタ` |
| アンカー | **A181** = `メーカー辞書` |
| ヘッダー | A182=`メーカー名`／B182=`区分`／C182=`メーカー・問屋半角英字`（旧「メーカー名ベース」も読取可） |
| データ | A183〜 |
| 読取 | ラベル `メーカー辞書` を探して下を読む（行固定にしない） |
| Step1 | AIのメーカー名で照合 → マスタの `メーカー名ベース`・`メーカー名`・`区分`・`メーカー・問屋半角英字` を埋める |
| シード | 初回はマスタから登録。**手修正を正**とする |
| **月次** | メニュー **Z→15-⑬ メーカー辞書をマスタから更新（月次）**: 新規キーのみ追記。既存の区分・半角英字は**上書きしない**（空欄のみ補完） |

トグル: `B_MAKER_DICT_ENABLED`（未設定=true）

## 3. ③ オリジナルカタログスラッグ

| 項目 | 内容 |
|------|------|
| 条件 | マスタ上方（または同一Step1バッチ内）に **同じJANの親行**がある |
| 生成 | 商品名の粗いローマ字＋短いハッシュ、**半角英数のみ・最大13文字** |
| 書き先 | `オリジナルカタログ商品名`（親）／子は親参照式。併せて `JANコードorオリジナルカタログ商品名` にもスラッグ |
| 条件外 | 従来どおり（1行目値／`=M$1` 等）＋ JANコードor には JAN |

トグル: `B_ORIGINAL_CATALOG_SLUG_ENABLED`（未設定=true）
