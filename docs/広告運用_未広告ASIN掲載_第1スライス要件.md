# 未広告ASIN掲載 — 第1スライス要件（ロック）

**最終更新**: 2026-10-16  
**ゴール**: 登録が新しいASINから順に、広告あり／なしを一覧し、人間がレ点した未広告を **オート＋マニュアル空枠ペア** で載せる。その後の最適化は従来どおり（オートで効いたKW→マニュアル）。  
**第1スライス範囲**: **一覧更新 → レ点 → バルク生成 → 人が一括操作でUL**（⑥API送信・Ads API作成は後回し）

関連: [Ads API 日本申請手順](広告運用_ADS_API_日本申請と取得手順.md)／[再申請初心者手順](広告運用_ADS_API_再申請_初心者手順.md)／既存最適化 [回答反映と今後の要件](広告運用_回答反映と今後の要件.md)

## 2. 処理イメージ（ロック）

```
SP-APIで出品一覧（出品開始日で新しい順）＋商品情報
  × Drive「広告中の商品」CSV（最新1本）で広告あり／なし付与
  → 一覧シート（レ点列あり）
  → 人間が「広告なし」にレ点
  → レ点行だけ オート＋マニュアル空枠ペアのバルクxlsx
  → 📦生成されたバルクファイル へ保存
  → 人が Amazon 一括操作で UL
  → 以後はレーンB（従来）でKW最適化
```

### 3.1 「広告中の商品」CSV運用（ロック）

| 項目 | 内容 |
|------|------|
| 方式 | **フォルダ保存**（シート手貼りは本線にしない） |
| 親 | 既存 `AMZ_FOLDER_ID` |
| サブフォルダ名 | `📥広告中の商品レポート` |
| 正のファイル | サブフォルダ内の **更新日時が最新のCSV 1本** |
| 人間 | Adsで「広告中の商品」をDL → 上記フォルダへ保存 |
| 頻度 | 一覧更新の前（週1〜隔週目安） |
| 空／古い | フォルダ空は **処理停止＋案内**。古い（例: 14日超）は **警告ダイアログのうえ続行可** |
| 参照用シート | 一覧更新時、GASが必要ならシートへ自動転記（人が貼らない） |
| 将来 | Ads API通過後、同じ「広告済み集合」をAPI取得に差し替え可。フォルダは予備 |

## 6. 実装方針（承認後）

- 置き場: `広告運用GAS/`（出品直下の聖域・楽天CSVに混ぜない）  
- SP-API認証: 広告運用GASの Script Properties（出品側と別プロジェクト。キーは人間が設定。Git禁止）  
- 既存の除外／入札バルク生成とは **別関数・別メニュー**  
- 必須3点: 本要件更新／調査ログ／`UNADVERTISED_ASIN_ENABLED` 等でOFF可  
- `clasp push` は人間（広告運用リポ）

```powershell
cd C:\Users\takuy\Desktop\gas-project\広告運用GAS
clasp push
```
