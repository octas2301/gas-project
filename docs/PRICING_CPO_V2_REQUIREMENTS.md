# Amazon CPO V2 要件定義（確定版）

## 1. 目的

- **旧CPO**（利益レール・送料込み最適化・F/P ガード等の GAS 後処理）が生む **競合−1 の上書き**や **単価連鎖の崩れ**を避ける。
- **新CPO（V2）** は **売値のたたき台** と **単価グラデーションの骨格** に特化し、**利益200円／100円・送料確定・最終単調**は **②.5・③** に任せる。

## 2. 処理順（標準）

1. **新CPO（V2）** … 競合・セット関係に基づく **税込売値のたたき台**（②.5 **前**は **送料はプロンプトに含めない**）。
2. **②.5 想定物流費** … 送料・サイズの確定。
3. **③** … **先に送料（サイズ・梱包指定）を調整し、それでも足りなければ売値**。  
   - **税引後利益：マイナス禁止**  
   - **原則200円厳守**、**競合がある行のみ100円まで**許容  
   - **単価・総額の逆転防止**は **③のみ**（本ドキュメントの **V2 では未実装・既存再③を引き続き利用**し、別タスクで拡張）

## 3. V2 のスコープ

### 3.1 行うこと

- Gemini に **`docs/CPO_PROMPT_V2.md`** と同一思想のプロンプトを送る（実装は `getCPOPromptTemplateV2()`）。
- **入力テーブル**（②.5 前）: `セット数 / セット卸値(税込) / 競合価格(Amazon)` のみ。**送料列は含めない**。
- **②.5 後・B-②** 相当で **送料参照を付けたい**場合: `includeShippingReference=true` で **確定送料列**を **参考**としてテーブルに追加（送料は **決めない**）。
- **競合がある子行**はすべて **`round(競合) - 1`** を優先（アンカー）。
- **競合が2行以上**（同一JANで競合価格が入っている子が2行以上）: 埋まっていない行は **アンカー間の単価を線形補間**（単価差がほぼゼロなら **1% フォールバック**）。
- **競合が0または1行**: 欠損埋めは **リスト順で隣との 1%**（単価）を使用。
- **単調補正**: セット数昇順で **1個あたり単価が非増加**、**総額が非減少**。**競合行の売価は下げない**（競合−1を維持）。矛盾時は **手前の非競合行の売値を上げる**ことで整合（両方競合で数学的に矛盾する場合は Logger に警告）。

### 3.2 行わないこと（V2）

- `applyProfitMarginRailsOnPrice_` による **上限マージンでの値下げ**。
- **F/P ガード**（送料/売価比率）による売値の引き上げ。
- **利益200／100円**の強制（セル色は **競合負け**のみ薄黄。利益での赤背景は **付けない**）。

### 3.3 旧CPO

- **関数** `runCpoProposePricesWithRound_` は **維持**。
- **Script Properties** `CPO_ENGINE` = `v2`（既定）| `legacy` で切替。

## 4. メニュー

| メニュー | 挙動（`CPO_ENGINE`） |
|----------|------------------------|
| `3. Amazon販売価格をAI提案(V2・単体)`（B統合） | **v2** → `runCpoProposePricesV2_` / **legacy** → round1 |
| `3b. Amazon販売価格をAI提案(2回目)` | **v2** → トーストのみ（V2は1回のみ） |
| `③ Amazon販売価格をAI提案`（連続2ラウンド） | **v2** → V2 を1回のみ / **legacy** → 従来 |
| `②.5後の Amazon CPO のみ` | **v2** → `runCpoProposePricesV2_({ includeShippingReference: true })` |
| **追加** `3. Amazon販売価格をAI提案(V2・単体)` | 常に V2（切替に依存せずテスト用） |

## 5. 未実装（次フェーズ）

- **③** の **送料列（サイズ＆自己発/FBA・梱包箱指定）を先に変える**ロジック、**ネコポス優先**の文章ルールのコード化。
- **セット構成の長文**を **親行の `競合AmazonページURL`** へ移す（列名固定・既存URLを壊さない運用要検討）。

3. **フェーズ3**: **再③**（または拡張③）。
