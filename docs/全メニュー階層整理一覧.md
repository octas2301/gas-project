# 全メニュー階層整理一覧

§9 要件定義に基づくメニュー構成。A/Z=2階層、B/C/D=階層なし。実装は `コード.js` の `onOpen` および `createZSplitMenu` を参照。

## 第1階層（AI出品ツール直下）

| メニュー | 階層 | 内容 |
|----------|------|------|
| **A.** ASIN貼付⇒Keepa抽出（token制限注意） | 2階層 | 1. 2. 3. Keepa取得（20/50/全件） |
| **B.** 商品構成/情報の一括生成（長時間、夜推奨） | 階層なし | menuRunBIntegrated（②→④→③→⑤→一括生成→同期→プルダウンを順実行。時間制限で切れた場合はトリガーで続きから再開。§8.3.1。§8.8のとおり確認ダイアログ廃止済み） |
| **B-①** amazon競合価格のみKeepa修正を反映 | 階層なし | menuUpdateCompetitivePriceOnly（ASIN貼り付けで直した競合価格・ASIN・URLをマスタに反映。価格再提案は行わない） |
| **B-②** 送料・競合価格修正後、価格を再設定（全モール） | 階層なし | menuRunPriceProposalOnly（④楽天Yahoo V2→③Amazon②.5後V2→再③。入荷後・競合修正後の再提案用） |
| **C.** 画像フォルダ保存⇒商品紐付け（少数推奨） | 階層なし | generateAiImageMatrix |
| **D.** 画像＋出品全モール一括アップロード（選択可） | 階層なし | showBatchExportModal |
| **Z.** 分割して実行できるメニュー一覧 | 2階層 | 1.～10.／11.～17.／99. |

## Z. 直下（1.～10. 主フロー）

1. セット構成 / 2. 不足セット抽出 / **3. Amazon…(V2・単体)** / **3.1 想定物流費（単体）** / **3.2 楽天Yahoo!…(V2・単体)** / **4. 再③** / 5～10（出品取得・同期・商品名案・CSV・一括出品・CKクリア）。**旧CPO（legacy）** サブメニューに Amazon 連続2ラウンド等・旧⑤。

## Z. 直下（11.～17. 補助・99. テスト）

- **11. シート・マスタ** … 11-① シート初期化 / 11-② マスタ列確認 / 11-③ 商品名案のみ生成
- **12. Amazon補助** … 12-①～12-⑥（ASIN準備・リセット・セット数提案・販売価格提案・Keepa競合・リサーチCSV反映）
- **13. 楽天補助** … 13-① 楽天競合 13-② 楽天セット別
- **14. Yahoo!補助** … 14-① Yahoo!競合 14-② Yahoo!セット別
- **15. 共通・検証** … 15-①～15-⑫（列番号マスタ・計算式・競合入力・メーカー品番・SerpAPI・モール横断・抜け挿入・価格提案・Amazonカテゴリー）
- **16. 楽天削除・URL・反映停止** … 16-①～16-⑤
- **17. 計算式・診断** … 17-①～17-④
- **99. テストメニュー** … 99-①～99-⑧

詳細な対応処理名は `コード.js` の `createZSplitMenu` を参照。
