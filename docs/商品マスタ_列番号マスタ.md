# 商品マスタ 列番号マスタ

▼商品マスタ(人間作業用) の**ヘッダー行は 8 行目**です。それより上は人間用の説明行のため、列番号マスタは 8 行目をヘッダーとして生成します。

## マスタデータの形（全列項目で整理）

- **格納先**: 同一スプレッドシート内のシート「**列番号マスタ**」
- **列構成**:
  - `列番号(0-based)` … 左から 0, 1, 2, …
  - `列字母` … A, B, …, Z, AA, AB, …（スプレッドシートの列字母）
  - `列項目名` … 8 行目のヘッダー文字列（そのまま）

## 変更時の運用

- ヘッダー（列の追加・削除・順序変更・列名変更）をした場合 → **列番号マスタを再生成**する。
- メニュー「**AI出品ツール**」→「**商品リサーチ**」→「**② 出品用**」→「**⑨ その他個別メニュー**」→「**共通**」→「**列番号マスタを生成（8行目から）**」を実行すると、**▼商品マスタ(人間作業用) の 8 行目**をヘッダーとして読み取り、「列番号マスタ」シートに全列のマスタを上書きします。
- **対象は「▼商品マスタ(人間作業用)」シートのみ**です。他シートはヘッダー行が異なるため、必ずこのシートを開いた状態で実行してください。
- マスタを修正する指示（列レイアウト変更）が出た場合は、上記メニューを実行すればマスタが更新され、**Amazon 商品名計算式**も「Amazon商品名計算式を表示（コピペ用）」で再取得すれば連動します。

## 計算式の取得（コピペ用）

- **メニューから取得**: 「**共通**」→「**Amazon商品名計算式を表示（コピペ用）**」を実行すると、列番号マスタを元に **Amazon 用の商品名つなぎ計算式** がダイアログに表示されます。表示された式をコピーしてセルに貼り付けてください。
- **チャットで受け取る**: 計算式をすぐ欲しい場合は、AI（Cursor 等）に「Amazon商品名計算式をチャットでください」と依頼すると、コード内の `DEFAULT_AMAZON_PRODUCT_NAME_FORMULA_SAMPLE`（列字母 B〜K のサンプル）を元に渡します。列構成が異なる場合は、列番号マスタの「列字母」に合わせて B,C,…,K を置き換えるか、上記メニューで表示される式を使ってください。
- いずれも `ROW()` で行を参照するため、貼り付けた行のデータが参照されます。「列番号マスタ」シートが存在しない場合は、先に「列番号マスタを生成（8行目から）」を実行してください。

## 定数（コード.js）

- `COLUMN_MASTER_HEADER_ROW = 8` … ヘッダー行（1-based）
- `COLUMN_MASTER_SHEET_NAME = '列番号マスタ'` … マスタシート名
- `DEFAULT_AMAZON_PRODUCT_NAME_FORMULA_SAMPLE` … チャットで計算式を渡す用のサンプル（列字母 B〜K）。AI が参照してそのままチャットで渡せる。
